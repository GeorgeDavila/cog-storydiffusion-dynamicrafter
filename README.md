# cog-storydiffusion-dynamicrafter
use dynamicrafter to generate video from storydiffusion output images 

Example output using [storydiffusion](https://replicate.com/hvision-nku/storydiffusion) outputs on [tooncrafter](https://replicate.com/fofr/tooncrafter):

![ex1](https://github.com/GeorgeDavila/cog-storydiffusion-dynamicrafter/blob/5ebe3dfb37f2013944397cf62cdbc5b70757965f/examples/ex1.mp4)

(generated by running default example output of storydiffusion replicate api through tooncrafter default settings on June 4th 2024)
